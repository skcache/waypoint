# Waypoint — web app

Next.js (App Router) + TypeScript + Tailwind CSS frontend for Waypoint.

The scaffold currently renders a static status page. Interactive product
flows (workbench, checkout, trace explorer) arrive in later phases.

- Run: `npm run dev` — or `make dev-web` from the repository root
- Build: `npm run build`
- Lint: `npm run lint`

See the repository root `README.md` for full project context.
